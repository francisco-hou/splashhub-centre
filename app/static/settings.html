Settings

Team-wide: a change here applies to everyone using SplashHub Centre.

SOS Scans

AI review
Review new Custom SOS package requests with Claude as they arrive. Applies only to requests that arrive while it’s on; anything already listed keeps the decision it arrived with. Any request can still be reviewed by hand with its Run AI review button.
Auto add internal note
After every AI review (automatic or by button), add it to the Zendesk ticket as an internal note. Agents only; the customer is not notified. If it fails, the request says why.
Translate with
The engine behind a request’s Translate to English button. Claude: the best translations, a cent or two each. Spark: Splashtop’s own AI, free, a smaller model. A translation is made once per request and kept.
Scan a ticket
Read one ticket from Zendesk and list it on SOS Scans now; it gets an AI review if the switch above is on.
Past requests
Find every past “New SOS package created by…” ticket in Zendesk and list it on SOS Scans, its images shown from Zendesk. No AI review. Tickets already listed are skipped, and it carries on by itself after a restart.

Spark

Model
Which of Spark’s models answers: Ask AI, Spark translations, and the dashboard’s spike notes and lookalike names. Smaller models answer faster; bigger ones may answer better. Use Test speed to compare.
Let the model think first
Some models (like Qwen3) write a long hidden chain of reasoning before every answer. Off is much faster and fine for lookups, translations and tags; turn it on only if answers seem careless.

Price Book

Price feed
Where the Price Book reads its prices on splashtop.com. The link carries a version hash that changes whenever splashtop.com rebuilds; the Price Book re-finds it by itself, or scan here to do it on demand, or paste a link to set it by hand.
